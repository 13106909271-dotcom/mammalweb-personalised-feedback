# MammalWeb Personalised Feedback

Source code for my dissertation project on personalised retrospective feedback for MammalWeb volunteers.

## Files

- `dashboard.py` – recent-activity dashboard implemented in Streamlit.
- `annual_email.py` – Python code for generating the annual personalised summary email.
- `annual_email_template.html` – Jinja2 HTML template used to render the annual email.

The implementation was developed and tested using an extracted 2023 MammalWeb dataset.
